Portfolio 5.0 - React + Vite + Node.js + Express + MySQL

التشغيل:
1) ثبّت Node.js 18 أو أحدث.
2) شغّل MySQL.
3) افتح Terminal داخل مجلد المشروع.
4) نفّذ: npm install
5) نفّذ: npm run dev
6) افتح: http://localhost:5173

السيرفر الخلفي يعمل على http://localhost:8000 وVite يرسل طلبات /api إليه تلقائيًا.

الإنتاج:
npm run build
npm start
ثم افتح http://localhost:8000

لوحة الإدارة:
http://localhost:8000/admin/login.html

الإعدادات موجودة في .env. لا تشارك ملف .env عند رفع المشروع إلى GitHub.
كيف اعدل الاسم لانو يظهر كبير وناقص
